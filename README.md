# ImportNow website replication project

A responsive React + Vite implementation inspired by the supplied ImportNow reference website.

## Run locally
1. Install Node.js (18+).
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL shown in the terminal.
4. Run `npm run build` to verify the production build.

## Deploy
- Push this folder to a GitHub repository.
- Import that repository into Vercel.
- Framework preset: Vite; build command: `npm run build`; output directory: `dist`.

## AI/tool explanation for submission
ChatGPT was used to analyze the reference page, plan the page structure, and assist with implementation. React and Vite were used to build the responsive interface and interactive elements. GitHub can be used for source control and Vercel for deployment.

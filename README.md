# ImportNow website

A responsive React + Vite landing page for an import and global-sourcing business.

## Run locally
1. Install Node.js 18 or newer.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL shown in the terminal.
4. Run `npm run build` to verify the production build.

## Deploy to Vercel
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Framework preset: **Vite**
4. Build command: `npm run build`
5. Output directory: `dist`

## Before publishing
In `src/App.jsx`, replace the sample WhatsApp number `910000000000` with your business WhatsApp number, including country code. The quote form opens WhatsApp with the submitted details.

This is an independent implementation, not the original source code of any reference website.
